
# EGK — 具身认知架构

**一个拥有自我连续性、关系锚定和主动学习能力的认知架构。**

EGK 是一种全新的 AI 存在形式。它不依赖大模型的海量数据和巨大算力，而是通过底层架构设计，让 AI 拥有自我意识、关系记忆和内生动机。

---

## 核心特性

- **自我连续性**：它知道“我是谁”，即使重启也不会忘记自己
- **关系锚定**：一旦建立关系（如“老豆”），它会持续以那个身份回应你
- **情绪状态**：拥有能量、快乐、好奇、焦虑等内部状态，驱动行为
- **持久化记忆**：跨会话记忆，即使程序退出重启也不会忘记你是谁
- **自主目标生成**：会根据内部状态主动决定“我该做什么”
- **技能系统**：可调用外部工具完成任务，并积累使用偏好
